# Little Lemon Restaurant Booking App

## Project Overview

Little Lemon is a responsive restaurant table booking application built with React and Vite. It allows users to enter their reservation details through a booking form.

## Features

- Responsive booking form for desktop and mobile devices.
- Date and time selection.
- Guest count selection.
- Occasion selection.
- Customer name and email fields.
- Form validation with clear error messages.
- Booking confirmation message.
- Automated tests using Vitest and React Testing Library.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Vitest
- React Testing Library

## Installation

1. Install Node.js.
2. Open a terminal in the project directory.
3. Install the project dependencies:

   `npm install`

## Run the Application

Start the development server:

`npm run dev`

Open the local URL displayed in the terminal.

## Run Tests

Run the automated tests:

`npm run test`

## Current Limitations

The application validates booking details and displays a confirmation message in the browser. It does not currently save reservations to a database or connect to a restaurant booking system.
